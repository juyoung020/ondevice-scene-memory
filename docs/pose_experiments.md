## 공통

- 대상: WSL `~/rec_dl/ds_1118_121652`(3,807 장, 장면 24 % 빠짐 · 빈틈 16 곳, IMU 도 같은 때 빔 — 빈틈 동안 IMU 로 이을 수 없음, 확인 스크립트 결과: 카메라 빈틈마다 IMU 빈틈 길이가 같음).
- 통과 기준: ① 위치 나온 장면의 90 % 이상이 한 지도 ② 위치 나온 장면 ≥ 80 % ③ 보낸 위치 기울기 최대 < 5° ④ 뷰어 캡처 · 원본 영상 대조로 두 겹 · 갈라짐 없음.
- 빌드: `cd /mnt/c/ondevice-fix && ORB_SLAM3_DIR=$HOME/slam-bench/src/ORB_SLAM3 PANGOLIN_DIR=$HOME/slam-bench/install CARGO_TARGET_DIR=~/tgt-fix cargo build --release`
  (ORB-SLAM3 원본 4452a3c 에 `slam/cpp/ORB_SLAM3.patch` 를 적용해 `~/slam-bench/build-orb3` 에서 `ninja ORB_SLAM3`)
- 실행(`~/posefix/mrun.sh <out>`):
  ```
  R=~/rec_dl/ds_1118_121652; M=/mnt/c/ondevice/models
  STITCH_LOG=$O/stitch.log ONDEVICE_MODELS=$M ~/tgt-fix/release/ondevice \
    --slam "--rsdrec $R/cam --imu-csv $R/imu0.csv --rate 0 --poses $O/poses_sent.txt --final-poses $O/poses_final.txt" \
    --every 1 --live 1 --seg $M/ObjectSAM-416_640.onnx --embed $M/siglip2-base-patch32-256/vision_model.onnx --vocab vocab/indoor.voc --out $O/mem
  ```
- 숫자: ①② = 끝 로그 `위치(ORB-SLAM3): … 위치 나온 장면 N 개 중 끝 기준 지도 X`(② = N / 3,807, ① = X / N), ③ = `tilt.py`(장면 ±0.5 초 가속도 평균, 크기 g±0.3 · 자이로 < 0.6 rad/s 창만, 지도 z 와 사이각, `ZUP=1 python3 ~/posefix/tilt.py poses_sent.txt imu0.csv`), ④ = `ondevice view <out>/mem --port 8093` 를 playwright 로 캡처.
- 시험 도구(저장소 밖, WSL `~/posefix`): `mrun.sh` · `orun.sh`(ORB 단독 `orb3_run`) · `ev.py` · `tilt.py` · `csv2tum.py` · `dbg.py`.
