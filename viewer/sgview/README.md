# sgview — 장면 그래프 뷰어 (Rust) · 이것이 지금 뷰어다

**Spark-DSG 장면 그래프 보기 = sgview.** 물체 기억(scene graph, Spark-DSG 형식 `scene.json`·`view.json`)을 보는 뷰어는 이것 하나다
(spark dsg viewer / scene graph viewer / 물체 기억 뷰어). Rust 서버 + three.js, 파이썬 없음.

| 하고 싶은 것 | 명령 (robot-agent 저장소 루트) |
|---|---|
| 탐사 한 판 + 실시간 뷰어 한 번에 | `tools/run_explore_live.sh [policy] [task] [tag]` — LIMO 는 `SGRT_ROBOT=limo_omx tools/run_explore_live.sh …` |
| 실시간 스트림 받기(60 Hz 이상) | `tools/run_sgview.sh <memory_dir> --live` + 시뮬/로봇 쪽 `SGRT_STREAM=127.0.0.1:9001` |
| 녹화된 메모리 폴더 보기 | `tools/run_sgview.sh <memory_dir>` |
| 기록 폴더 보기(파일 모드) | `src/sim/explore/viewer_8080.sh <run dir>` 또는 아래 직접 실행 |

실시간 경로: C++ libsgrt → 소켓(`SGRT_STREAM=127.0.0.1:9001`) → Rust 서버(`--ingest`) → SSE → 브라우저. 브라우저에서 http://localhost:8080 .

Rust 서버(std + `serde_json`·`flate2`)가 `view.json`,
`map.pgm`/`map.yaml`, `objects/O<id>_*` 를 서빙하고, 그리기는 three.js(`assets/`에 같이 넣음, 인터넷 불필요).

```bash
cd src/scene_graph/sgview && cargo build --release
target/release/sgview <memory_dir> [--port 8080] [--bind 0.0.0.0]
```
브라우저에서 http://localhost:8080 . 서버가 폴더의 `view.json`·`pose.json` 을 50 ms 마다 살펴 바뀌면 `/stream`(SSE)으로 알리고(`vv` 판 번호 · `fpose` 빠른 카메라 자세), 페이지는 그때만 `/api/view` 를 한 번 받는다. 가만히 있는 뷰어는 요청을 보내지 않는다(10 s 마다 keepalive 한 줄). 이벤트 스트림이 끊기면 다시 붙을 때까지 2 s 마다 폴링한다.

불러오기: 표면 구역·점 노드는 `/api/files?p=a,b,…`(파일 여러 개를 한 응답에, 파일마다 `u32 이름 길이·이름·u32 길이(없으면 0xffffffff)·내용`, ETag = 경로와 파일 판의 해시)로 16 구역·12 노드씩 묶어 받는다. PLY 풀기·정점 법선·JPEG 아틀라스 디코딩(`createImageBitmap`)은 페이지 안 Web Worker(인라인, 별도 파일 없음)가 하고 배열·비트맵을 넘겨 주므로 본 스레드는 지오메트리만 만든다.

## 화면 (발표용 기본값)
- 어두운 그라데이션 배경 + 옅은 바닥 격자·바닥 그림자 위에 표면 지도만 보인다. 열면 표면 지도를 3/4 위쪽 시점으로 자동으로 맞춘다.
- 표면 셰이딩: 반구광 + 부드러운 햇빛, 뒷면(구멍·들쭉날쭉한 가장자리로 보이는 안쪽)은 어둡게, 보는 거리를 따라가는 안개.
- 물체: 마우스를 올리면 파란 윤곽 상자 + 알약 모양 이름표(이름 · 상태), 클릭하면 노란 윤곽으로 선택, 빈 곳 클릭·Esc 로 해제.
- 우상단 도구줄: Fit · Top · Demo(천천히 자동 회전) · 화질(High/Low) · Settings(설정 패널, 기본은 접힘).
- 단축키: F 맞춤, T 위에서, R 데모 회전, G 설정 패널, H 화면 글자·버튼 전부 숨김.
- 깊이 음영(EDL)은 두 화질 모두 켜져 있다(전체 화면 후처리 한 장).
- 화질: High = 화소 비율 최대 2 + 점 지도 예산 3 M 점 + 점 섞기(포물면 점·가중 평균), Low = 화소 비율 1 + 0.8 M 점·노드를 덜 세밀하게(화면 점 간격 약 4 화소, 적응 점 크기가 면을 메움). 약한 GPU 는 캔버스 다중 샘플링 없이 만든다(장면은 다중 샘플링 없는 EDL 목표에 그려지므로 화면 차이 없음). 약한 GPU(Pi 5 V3D·모바일·소프트웨어 렌더러)는 Low 로 시작하고, 고른 값은 브라우저에 기억된다.
- 점유 지도·궤적·카메라 표시·물체 이름표 전부·2D 벽·그래프 층은 설정 패널에서 켠다.
- 주소 인자(시연·스크린샷): `?quality=high|low`, `?ui=0`(글자·버튼 숨김), `?panel=1`, `?demo=1`, `?sel=<물체 id>`, `?cam=ex,ey,ez,tx,ty,tz`, 체크 상자 `?c_map=1`·숫자 칸 `?n_edl=0.4` 처럼, 점 지도 예산 `?budget=<점 수>`·노드 세밀함 `?refine=<배수>`(High 1.0 · Low 2.2), 이벤트 스트림 없이 2 s 폴링 `?poll=1`(headless 스크린샷 도구용), 불러오기 측정 `?perf=<ms>`(그 시각에 요청 수·바이트·본 스레드 긴 작업·마지막 데이터 시각을 페이지 제목에).
- 전후 비교: `docs/results/viewer_before_*.png` · `viewer_after_*.png`.

## 3D 점 지도 (Potree 방식)
memmap 이 쓴 점 옥트리(`scene_points.octree`, 형식은 `docs/bridge.md` "3D 점 지도")를 Potree 처럼 그린다.
- **고르기**: 프레임마다 화면 안 노드를 화면 반지름이 큰 것부터(이진 힙) 고르고, 노드의 점 간격이 화면에서 약 2 화소(Low 4 화소) 아래가 되거나 점 예산(High 3 M · Low 0.8 M · `?budget=`)에 닿으면 멈춘다. 없는 노드는 큰 것부터 한 요청에 12 개(또는 30 만 점)까지 묶어 두 요청씩 받고, 받아 둔 점이 예산의 2 배를 넘으면 오래 안 쓴 노드를 버린다.
- **점 크기**: 둥근 점, 지름 = 그 자리 점 간격 × "3D map point size"(기본 1.3), 화면에서 1.5–50 화소. 그 자리 점 간격은 Potree 의 보이는 노드 텍스처로 구한다: 그리는 노드를 너비 우선으로 한 줄 텍스처에 놓고(자식 마스크 + 첫 자식까지 거리), 정점 셰이더가 점 위치로 가장 깊이 그려진 노드까지 내려가 그 수준의 간격을 쓴다. 굵은 노드의 점도 세밀하게 받은 곳에서는 고운 점만큼 작아져 면이 덩어리 없이 닫힌다.
- **그리기**: 노드마다 그리기 호출 하나, 재질·셰이더는 모든 노드가 하나를 같이 쓰고 노드 번호·간격 두 값만 그리기 직전에 바꾼다. 보이는 노드 텍스처는 그리는 노드 묶음이 바뀔 때만 GPU 에 올린다. 시점이 멈추면 다시 그리지 않는다.
- **EDL**: Potree `edl.fs` 와 같은 식(이웃 8 개 · 반경 1.4 화소 · log2 시점 거리 차의 합 × 300 × 세기 0.4). 한 면 안에서 겹친 점끼리의 작은 깊이 차(기본 0.025, 약 1.7 %: Kinect 깊이 잡음 크기)는 빼고 세어 물체 윤곽·단차만 어두워진다.
- **High 의 점 섞기**("Blend point splats", Potree 고화질 점과 같은 생각): 점은 화면 쪽으로 볼록한 포물면 깊이(가장자리가 반지름 × 0.5 만큼 깊음)로 그려져 겹친 점끼리 부드럽게 만나고, 둘째 패스가 점 지도만 반정밀도 부동소수 목표에 그린다 — 가장 앞 면 뒤 좁은 깊이 띠(점 반지름 × 1.5, 거리의 0.6 % 이상) 안의 점 색 × 가중치(1 − r²)를 더하고 마지막 패스에서 나눈다. 가까이서도 원판 알갱이 대신 이어진 면으로 보인다. Low 는 평평한 원판 한 패스(Pi 5 GPU, 조각 깊이 쓰기 없음).
- 색은 사진 색(sRGB) 그대로 화면에 쓴다(저장된 색 = 그려진 색, 흰 책상 약 190). 바닥 패드·격자는 점 지도 상자 아래에 놓인다.
- 점 지도가 있으면 물체 분할 점("Segment points")은 기본으로 꺼진다(같은 자리를 큰 원판으로 덧그려 덩어리처럼 보이므로).
- 표면 지도가 함께 있으면 표면이 기본이고 점 지도는 "3D map points" 로 켠다.
- 그림: `docs/results/potree_before_*.png`(예전 네모 점) → `potree_after_*.png`, 표면 지도 `potree_mesh_*.png`, Potree 예제 `potree_reference.png`.

## 보이는 것 (설정 패널에서 켜는 것 포함)
- 점유 지도, 로봇(원판 + 화살표), 물체 세그먼트 점구름(true/state colour), 이름표, 천장 숨김(기본), 구조물/gone 켜고 끄기.
- 공중에 뜬 그래프 2층: 물체(z 4 m, 상태 색 + 썸네일), 방(그 위 층 간격 2 m) + 에이전트 궤적(바닥), 간선(층 안·방→물체). 장소·전치사 관계·building·frontier 는 그리지 않는다.
- 2D 벽(하늘색 선) + 벽 상태 벡터(길이 56) + "Save wall state" 로 JSON 저장.
- slam 지도는 출발 자세 좌표라 벽이 기울어져 있다(예: turning_on_radio 출발 yaw 49°). 벽 선분은 `wallSegmentsAligned` 로 벽 방향 θ 에서 찾고(`/api/walls`·`walls` 이벤트에 `theta`), 페이지는 \|θ\| > 1° 면 점유 지도를 θ 로 돌린 격자로 다시 뽑아 그린다(칸 계단 → 곧은 벽, 보기만 바뀜). gt 지도(축에 맞음)는 예전과 같다. 선분은 원래 격자의 점유 띠에 다시 맞춰 벽 위에 놓인다(scenemap `wallSegmentsAligned`).
- 궤적 라벨은 로봇 이름: `view.json` 의 `robot`, 없으면 `/api/robot`(실행 폴더 `robot_footprint.json` 의 `robot`, 옛 파일은 AABB 크기로 LIMO 판정), 모르면 "robot".
- 물체 클릭(그래프 노드 12 px 안 → 아니면 경계 상자 광선) 또는 드롭다운 → 정보 표 + RGB/마스크/깊이 조각.

## 실시간 모드 (파일 없이, 60 Hz 이상)

시뮬/로봇 프로세스(`sgrt`)가 소켓으로 바로 보내고, 서버가 브라우저에 SSE 로 흘려 준다. 파일은 거치지 않는다(이미지·점구름 같은 큰 파일만 `/file/` 로).

```bash
sgview <memory_dir> --port 8081 --ingest 127.0.0.1:9001          # 1) 뷰어: 9001 로 프레임을 받는다. memory_dir 은 sgrt 의 out 폴더(이미지·점구름 파일 위치)
SGRT_STREAM=127.0.0.1:9001 SGRT_STREAM_HZ=60 SGRT_MAP_EVERY=1 <시뮬 실행>   # 2) sgrt 가 스트림을 연다(요약 주기 기본 60 Hz, 최대 240)
```

```
sgrt(C++) ──소켓(프레임)──▶ sgview(Rust) ──SSE──▶ 브라우저(three.js)
 스텝 스레드: 링 버퍼에 복사만            상태 보관 + 방송          60 fps+ 렌더, 자세 보간
```

- **스텝 스레드는 아무것도 기다리지 않는다** (`scenemap/stream.hpp`): 락·시스템 호출·할당 없는 단일 생산자 링 버퍼에 복사만 하고 별도 스레드가 비차단 소켓으로 보낸다. 자세 ≈ 0.2~0.3 µs, 지도 바뀐 영역 10 KB ≈ 0.5 µs. 뷰어가 느리거나 끊겨도 스텝은 안 막힌다(링이 차면 그 프레임만 버림). 다시 붙으면 송신 스레드가 들고 있는 그림자 지도·요약·자세로 전체 상태를 다시 보낸다.
- **보내는 것**: 자세(`pose`), 지도 바뀐 영역만(`map`, 격자 변화 추적), 물체·방·로봇 궤적 요약(`view`, PLACES 는 뺌, 안 바뀌면 안 보냄), 벽 선분·벽 상태 벡터(`walls`, 서버가 C++ `walls.cpp` 로 계산, 선분은 바뀔 때만).
- **브라우저**: 자세는 표시 주기(60 fps+)로 지수 보간, 지도는 바뀐 행만 텍스처에 쓰고, 요약은 기하에 영향 주는 값(위치·상태·점 버전 …)이 바뀔 때만 다시 그린다. 새 시뮬 실행이 붙으면 `reset` 으로 이전 화면을 비운다. 설정 패널(G) 맨 위에 단계별 비용(HUD)이 보인다.
- **합성 부하 시험**: `scenemap/tools/stream_sim <memory_dir> 127.0.0.1:9001 24 240 60 60` — 자세 240 Hz, 지도 60 Hz, 요약 60 Hz 를 보내 본다. 측정(GPU 브라우저): 받은 주기 pose 240/s·map 60/s·view 60/s, 이벤트 처리 0.00~0.27 ms, 렌더 60 fps(디스플레이 상한, 프레임 0.4 ms), 시작 첫 데이터 16 ms · 장면 완성 213 ms. 송신 쪽 pushPose 평균 227 ns, 버려진 프레임 0.
- 시뮬 자체가 자세를 7 Hz 정도로만 내보내면(Isaac Sim 렌더 속도) 뷰어는 그 사이를 보간한다. 추론 주기(10~20 Hz)가 얼마든 뷰어가 병목이 되지 않게 한 것.
- 파일 모드(`sgview <memory_dir>` 만)는 녹화된 폴더를 보는 용도로 그대로 있다.
- **지도 갱신 주기 분리 (`SGRT_MAP_EVERY=n`)**: 점유 지도를 검출 키프레임(`kf_every`, 기본 6 스텝)이 아니라 n 스텝마다 깊이만으로 갱신한다(스캔 ≈ 0.47 ms + 격자 ≈ 0.07 ms). 검출·물체 지도·임베딩은 키프레임 그대로. 0/미설정 = 예전 동작. 같은 시나리오 측정: 지도 갱신 초당 2~3번 → 14번(자세와 같은 주기), 스텝 평균 1.01 → 1.52 ms, 탐색 커버리지 0.906 → 0.927(나빠지지 않음).
- **관절·상태 벡터 프레임(`joints`)**: `sm_push_proprio` 의 벡터를 그대로 스트림에 싣는다(로봇별 순서는 URDF 가 정함). 지금은 받아서 보관만 하고(`jointsCur`), URDF 모델을 올릴 때 이 값으로 로봇을 움직인다.
- 카메라는 지도가 커지는 동안 자동으로 따라가고(직접 조작하면 멈춤, `Fit` 으로 다시 켬).
