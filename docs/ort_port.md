# ort → Rust 이식 기록

## SigLIP2 글 인코더 (viewer/sgview/src/textnet.rs)

- sgview 에서 ort 제거, 기능 이름 `search`. 가중치 재배치, F16C/FCVTL, AVX-512/AVX2/NEON FMA 커널, qkv 합침, exp/GELU 다항 근사.
- 대조(데스크톱 WSL, 1,352 문장, ort 출력 기준): 최소 코사인 0.9999983, 최대 |오차| 4.95e-3.
- 검색 순위(문장끼리 최근접): 1위 일치 97.9 %, 상위 10 겹침 99.7 %. 어긋난 1위는 점수 차가 오차 수준인 근접 동점.
- 속도(8 스레드, 문장당 중앙값): Rust 95.6 ms, ort 78.1 ms. 측정 때 다른 작업으로 부하 평균 약 30 — 신뢰 낮음, 한가할 때 재측정 필요. 보드 확인 필요.
